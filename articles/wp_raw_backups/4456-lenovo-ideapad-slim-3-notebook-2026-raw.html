❓ Perguntas Frequentes sobre o Lenovo IdeaPad Slim 3 15IRU10

Qual versão do Lenovo IdeaPad Slim 3 15IRU10 devo comprar?

Recomendamos a versão 512GB + Windows 11 (R$ 3.314) para a maioria dos usuários. Ela oferece o dobro de armazenamento por apenas R$ 233 a mais. Se você tem experiência com Linux, a versão de R$ 3.081 é imbatível em preço.

Dá para fazer upgrade de RAM no Lenovo IdeaPad Slim 3 15IRU10?

NÃO. A memória de 8GB é soldada diretamente na placa-mãe e não pode ser expandida. Essa é uma limitação importante se você planeja usar o notebook por 5+ anos com muitos programas abertos.

Posso instalar Windows na versão Linux?

SIM, é possível. Você pode comprar a versão Linux e instalar Windows manualmente, mas precisará comprar a licença separadamente (~R$ 400-700). Se não tem experiência técnica, compre direto a versão com Windows.

IdeaPad Slim 3 é bom para estudar?

SIM, é uma excelente escolha para estudantes. O notebook é leve (1.63kg), portátil, tem boa bateria (~6-8 horas) e desempenho suficiente para navegação, Google Docs, videoconferências Zoom e streaming de aulas.
