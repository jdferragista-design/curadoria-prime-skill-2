# Template — guia / comparativo

Referência de recorte: presentes, volta às aulas, faixa de preço.
As regras absolutas valem iguais às do review.

Antes da lista: `RELATÓRIO DE MERCADO`
([skill curadoria-mercado](../../curadoria-mercado/SKILL.md)).
SKU **FORA** ou **SEM DADO** não ganha card.

Um produto só entra se:

1. existe página oficial conferível;
2. há venda em loja confiável no Brasil — ou o alerta de importado
   está explícito;
3. há relatos publicados **ou** teste independente **ou** review
   próprio documentado no site;
4. dá para dizer **para quem não é**.

Se o editor pedir para encaixar item que falha nisso, recuse ou
abra um box “ficou de fora, e por quê”.
