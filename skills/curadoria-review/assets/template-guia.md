# DEPRECATED — template-guia.md

Status: NÃO USAR PARA GERAÇÃO DIRETA
Data: 19/08/2026

Este arquivo permanece somente para compatibilidade com referências
antigas.

A Curadoria Prime possui atualmente três formatos:

REVIEW
→ `template-review.md`

VS de 2–3 produtos
→ `template-vs.md`

LISTA/GUIA de N produtos
→ `template-lista.md`

Portanto:

- "melhores X";
- "Top 5";
- "7 presentes";
- guia de compra multi-produto;

devem usar:

`template-lista.md`

Comparação direta:

`template-vs.md`

Review individual:

`template-review.md`

Guias regulatórios especiais, como conteúdo centrado em regra/limite/
proibição, devem ser explicitamente classificados pelo SKILL antes de
usar qualquer variante específica.

NÃO use o antigo Markdown deste arquivo como template.
